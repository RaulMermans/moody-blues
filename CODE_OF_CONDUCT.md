# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful and constructive, and assume good faith. Harassment and personal attacks are not accepted, in any project space.

To report a concern, contact the maintainer through [their GitHub profile](https://github.com/RaulMermans). Reports are handled
privately, and the maintainer may remove content or block participants who break this code.
