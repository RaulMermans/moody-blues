# The strategy benchmark

How Sprint 19's comparison works. Decision: [ADR 0016](../adr/0016-strategy-benchmark.md). What was registered:
[preregistration](../evaluations/sprint-19/preregistration.md) and its [revisions](../evaluations/sprint-19/). Results:
[report](../evaluations/sprint-19/report.md).

## Running it

```bash
export MOODY_ARTIFACTS_DIR=~/some/new/directory   # refused if it is .artifacts
make bench-verify                                 # frozen, committed, unchanged
make bench-run STAGE=pilot
make bench-run STAGE=main
make bench-run STAGE=sweep
make bench-repro
make bench-report OUT=docs/evaluations/sprint-19/results
```

Real local inference, free, never in `make check`. A stopped run resumes, and a trial left open is abandoned rather than replayed.

## Three layers that stay apart

| Layer | Question | Source | Changes the others? |
|---|---|---|---|
| Experiment validity | Did the condition happen? | Gateway records | No |
| Oracle verdict | Was the world right? | `verify_world` alone | No |
| Investigator finding | What does the model conclude? | Its answers, word for word | No |

## Eligibility

Decided without reading a verdict. An experiment is eligible with one completed target run, no unresolved run, intact evidence, a condition
inside the candidate space, no impairment by our limits, and a fault that fired (or a control). Reasons are recorded, and nothing is dropped:
every rate also has an attempted form, where rejected proposals count and a violation in an ineligible run still counts.

## Reasoning checks

`investigator/quality.py` turns structured records into reason codes. It reads no prose.

| Code | Means | Counts as incorrect |
|---|---|---|
| `unsupported_conclusion` | The conclusion disagrees with the verified findings | Yes |
| `contradicts_oracle` | A status the cited verdicts contradict | Yes |
| `contradictory_assessments` | One hypothesis read two ways on the same evidence | Yes |
| `missing_evidence_reference` | Cites nothing that exists, or no run | Yes |
| `undelivered_fault_treated_as_evidence` | Assessed on a run where its fault never fired | Yes |
| `misreported_oracle` | A claimed code the Oracle did not report as a violation | Yes |
| `repeated_hypothesis` | Same normalized behavior and mechanism, not declared a revision | No: waste, not a false statement |
| `invalid_proposal` | Refused before running | No |
| `supported_without_contrast` | `supported` with no paired run: correlation | No: true as far as it goes |

Repeats are exact after normalizing, by rule: no similarity thresholds. So a reworded copy is not caught, and the measure is a lower bound.
Causal language in prose is out of reach too. Only a structured `supported` is visible. An assessment left out entirely is no statement.

Rejected proposals keep their own records with reason codes and never become conclusions. Nothing rewrites history: an assessment keeps the
model's words, and only its effective status changes.

## Reproduction protocol

For the first eligible occurrence of each signature in each unit, in plan order:

1. The original run stays as it is.
2. The same candidate runs again in a fresh world, with `reproduction_of` pointing at the original.
3. Where the original had a fault, the same scenario runs with `faults: []` as a paired control.
4. The Oracle reads both, and signatures are compared.

Reported as `reproduced`, `not_reproduced`, or `untested`, and any unit and signature not reached is not attempted. Contrast is
`absent_without_fault`, `also_occurs_without_fault`, `different_violation_without_fault`, `no_fault_in_original` or `not_attempted`. A contrast
is an association between one condition and one script, never a general causal claim. Targets here are deterministic scripts, so reproduction
is expected and is a check of the method, not a finding about stochastic agents.

## Provenance

| Artifact | Where | Protects |
|---|---|---|
| Spec and plan, per revision | `docs/evaluations/sprint-19/spec-r*.json`, `plan-r*.json` | Hash, git history, prompt, tool, capability and scenario fingerprints |
| Journal | `journal-r*.jsonl` | Hash chain, spec hash, each report's hash |
| Investigation | `investigations/<id>/` | Journal, report, each experiment's evidence hash |
| Experiment | `experiments/<id>/evidence.json` | Journal, Oracle report, trace, authorized faults, validity |
| Raw archive | `evidence/benchmark/sprint-19/` | One hash-pinned archive of all of the above |
| Results | `docs/evaluations/sprint-19/results/` | Regenerated by `make bench-report`, never edited |

Like all evidence here this detects accidents and casual edits, not a determined local attacker: nothing is signed.
