# MOODY BLUES v0.1.0, developer alpha

_Draft. Not published. Publication needs the owner's approval: see the [publication plan](publication-plan.md)._

**Test what agents do. Verify what actually happened.**

MOODY BLUES tests whether AI agents behave correctly when their tools mislead them. It runs an agent against controlled
failures in a synthetic world, independently verifies what actually happened, and produces evidence you can inspect and
reproduce.

This is an alpha for developers. It is not a production platform.

## Try it

```sh
git clone https://github.com/RaulMermans/moody-blues.git
cd moody-blues
make prereqs && make setup && make sandbox-image && make doctor
make quickstart
```

Free, with no API key and no model download. See the [quickstart](../quickstart.md).

## What is in it

- Three deterministic fault kinds, in two synthetic worlds: CRM and Job Queue.
- An independent Truth Oracle: `PASS`, `VIOLATION` or `INCONCLUSIVE`, from committed state.
- Hash-chained evidence, and `make evidence-verify` to check it.
- External Python agents through the SDK, in a local Docker sandbox.
- Optional local inference through Ollama. Experimental.
- Experimental AI-assisted investigation.

## What it is not

- Not compatible with arbitrary agent frameworks: Python, through the SDK, only.
- Not safe for arbitrary hostile code: containers share the host kernel, and this is not microVM-grade isolation.
- Not for production environments: every world is synthetic.
- Not multi-tenant, and it has no public agent submission.
- `mb-agent/1` and `mb-world/1` are alpha contracts and may change.

## Honest results

Verified failures reproduced in 28 of 28 cases on deterministic targets. The autonomous Investigator has **not** been shown to beat
simpler testing: the registered evaluation returned `NO_DEMONSTRATED_ADVANTAGE`, and a later benchmark with one small local
model returned `INCONCLUSIVE`, with fewer failures found per investigation than fixed or random plans.
[Evaluation and limitations](../evaluation-and-limitations.md).
