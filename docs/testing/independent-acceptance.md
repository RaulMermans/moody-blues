# Independent developer acceptance test

**Status: `INDEPENDENT_DEVELOPER_ACCEPTANCE = NOT_RUN`.** No participant has taken it. It is the release's most important gate, and
it stays open until a real person completes it.

## Who qualifies

A developer who has not worked on MOODY BLUES. Not the author, and not a coding agent or an LLM simulation.

## What to give them

A link to the repository. Nothing else: no hidden steps, and no help. Say this:

> Please try this project from its README, on your own machine, and think out loud. I can't help you. If you get stuck for ten
> minutes, say so and we will stop there, which is a useful result.

## Tasks

1. Explain what MOODY BLUES does.
2. Install the prerequisites.
3. Run the free example.
4. Find its investigation.
5. Say what the Oracle concluded.
6. Explain the difference between the tool's response and the actual state.
7. Reproduce a verified failure.
8. Run or adapt an example agent.
9. Find and verify the evidence.
10. Clean up.
