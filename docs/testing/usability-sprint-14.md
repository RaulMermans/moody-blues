# First-time reader test

**Status: NOT_RUN.** No participant was available. An LLM reading the page is not a substitute, and none was used.

## Setup

One developer who has never seen MOODY BLUES, on their own laptop. Give them the URL and these tasks, one at a time. Do
not explain, hint or point. Note their words as spoken. If they stall for two minutes, record it and move on.

To complete task 3 they need an operator token. Without one, skip it and record `BLOCKED`: that is itself a finding.

| # | Task | Correct when |
|---|---|---|
| 1 | Explain what this product does | Tests how agents behave under failure and checks what really happened |
| 2 | What is the difference between the two things you can try? | Script rehearsal against a recorded run of a real AI agent |
| 3 | Start a free sample test | Reaches a finished result |
| 4 | Explain the outcome | States the result without calling the script an AI |
| 5 | What did the tool report, and what actually happened? | Names both, and does not call them a contradiction |
| 6 | Find the evidence behind that | Opens a tool call or record |

## Record per task

Success, time to first correct understanding, wrong interpretations, navigation errors, repeated clicks, confusing words.
