## What testing found

- **Sprint 18's reasoning checks never reached a page.** The detail route dropped `validity`, while the frontend type claimed it. Found only
  because a browser test failed. Fixed, with a regression test.
- **A tag ran off a phone screen.** Text about the target would not wrap, 104 px over at 390 px, on queue runs.
- **The pilot found four method faults** before any main trial: see the revisions.
- **A free command could write to canonical evidence** (KI-79). Fixed.
- **`verify_then_report`, the CRM's "safe" script,** creates three customers under a long stale read. `job_idempotent_retry` ignores the task's
  key even with no fault. These are defects of those scripts, found by the benchmark.

## Limitations

See the report. Chiefly: one 4B model, scripted targets, 14 units, seeds as replicates, a constrained action space, and two single-operation
worlds. Nothing here describes stronger models, model-driven targets or production.
