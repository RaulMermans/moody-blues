# MOODY BLUES — frontend

Next.js 16 (App Router, strict TypeScript, Tailwind v4). See the root [README](../README.md)
for setup and commands, and [AGENTS.md](../AGENTS.md) for development rules.

- `src/app/api/status/route.ts` — server-side proxy to FastAPI (`MOODY_BACKEND_URL`, read at
  request time). The browser never contacts the backend or any model provider directly.
- `src/components/status-panel.tsx` — renders backend connectivity and integration states
  exactly as the backend reports them.
- `e2e/` — Playwright tests against the real backend (`pnpm test:e2e`; requires `pnpm build`).
- `src/design/` — the design system the product uses: see [docs/design](../docs/design/README.md).
- `src/app/design-lab/` — a local specimen page, absent from production builds.
- `e2e-design/` — rules, truth, navigation, axe and WebKit checks on the real recorded evidence.

`AGENTS.md` in this folder is generated by Next.js and is re-added by `next dev`.
